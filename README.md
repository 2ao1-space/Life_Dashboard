# Life Dashboard v1

Life Dashboard هو تطبيق ويب ذكي يجمع بين إدارة المالية اليومية، تتبع الصلوات، كتابة الملاحظات، ومتابعة الصدقة في مكان واحد. تم تصميمه ليعمل كـ PWA Offline-First، بحيث يمكنك استخدامه حتى بدون اتصال بالإنترنت ثم تتم مزامنته تلقائياً عند العودة للاتصال.

## المميزات

- تسجيل دخول وانشاء حساب مع فصل بيانات كل مستخدم
- العمل بدون اتصال باستخدام IndexedDB عبر Dexie
- مزامنة تلقائية مع Supabase عند توفر الإنترنت
- تتبع الدخل والمصروفات والرواتب والصدقة
- نظام صدقة تلقائي بنسبة 2.5% من الدخل
- تقارير شهرية ورسوم بيانية
- تقويم تفاعلي
- وضع ليلي
- إمكانية تثبيت التطبيق على الجهاز كـ Progressive Web App

## التقنية المستخدمة

- Next.js
- React
- TypeScript
- Tailwind CSS
- Zustand
- Dexie (IndexedDB)
- Supabase
- Recharts
- Framer Motion

هذا المشروع مصمم كـ dashboard شخصي يساعدك على تنظيم حياتك اليومية بطريقة بسيطة وسريعة، مع التركيز على الخصوصية والقدرة على العمل دون اتصال.
